# General — SAC custom widgets

> Proprietary — © 2026 The Data Co (Pty) Ltd. All rights reserved. See [LICENSE](../../LICENSE).

Cross-industry visuals: calendars, process funnels and project timelines.

| Widget | What it shows | Folder |
|---|---|---|
| **Calendar Heatmap** | Daily values on a calendar grid (Gregorian or 4-4-5 retail) | [`General/Calendar Heatmap`](Calendar%20Heatmap) |
| **Order Flow Funnel** | Process-flow funnel with stage conversion | [`General/Order Flow Funnel`](Order%20Flow%20Funnel) |
| **Gantt Chart** | Timeline bars from start/end dates with swimlanes | [`General/Gantt Chart`](Gantt%20Chart) |

Each folder has its own README with the data model, properties and deployment steps.
