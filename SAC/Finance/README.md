# Finance — SAC custom widgets

> Proprietary — © 2026 The Data Co (Pty) Ltd. All rights reserved. See [LICENSE](../../LICENSE).

Financial reporting and analysis: income statement, revenue bridges, working capital and variance analysis. Currency switch: ZAR / USD.

| <a href="PVM%20Bridge"><img src="PVM%20Bridge/Example.png" width="260" alt="Price-Volume-Mix Bridge"/></a> | **[Price-Volume-Mix Bridge](PVM%20Bridge)** | Revenue bridge split into volume, mix, price and new/discontinued effects, with top product drivers |
| <a href="Ageing%20Buckets"><img src="Ageing%20Buckets/Example.png" width="260" alt="Ageing Buckets (AR/AP)"/></a> | **[Ageing Buckets (AR/AP)](Ageing%20Buckets)** | Debtors / creditors ageing by customer or vendor with overdue tiles |
| <a href="Variance%20Bridge"><img src="Variance%20Bridge/Example.png" width="260" alt="Variance Bridge"/></a> | **[Variance Bridge](Variance%20Bridge)** | Plan → Actual waterfall by driver, with Top-N + Other |
