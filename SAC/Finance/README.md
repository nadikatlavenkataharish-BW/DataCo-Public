# Finance — SAC custom widgets

> Proprietary — © 2026 The Data Co (Pty) Ltd. All rights reserved. See [LICENSE](../../LICENSE).

Financial reporting and analysis: income statement, revenue bridges, working capital and variance analysis. Currency switch: ZAR / USD.

| Widget | What it shows | Folder |
|---|---|---|
| **P&L Waterfall** | Income statement from revenue to net profit with automatic sub-totals and % of revenue | [`Finance/PnL Waterfall`](PnL%20Waterfall) |
| **Price-Volume-Mix Bridge** | Revenue bridge split into volume, mix, price and new/discontinued effects, with top product drivers | [`Finance/PVM Bridge`](PVM%20Bridge) |
| **Ageing Buckets (AR/AP)** | Debtors / creditors ageing by customer or vendor with overdue tiles | [`Finance/Ageing Buckets`](Ageing%20Buckets) |
| **Variance Bridge** | Plan → Actual waterfall by driver, with Top-N + Other | [`Finance/Variance Bridge`](Variance%20Bridge) |

Each folder has its own README with the data model, properties and deployment steps.
