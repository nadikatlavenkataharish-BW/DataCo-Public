# Retail — SAC custom widgets

> Proprietary — © 2026 The Data Co (Pty) Ltd. All rights reserved. See [LICENSE](../../LICENSE).

Retail performance and merchandise planning: store productivity, range classification, stock health and season sell-through. Currency switch: ZAR / USD.

| Widget | What it shows | Folder |
|---|---|---|
| **Store Performance Quadrant** | Stores on two KPIs (e.g. sales/m² vs margin %) in four labelled quadrants, bubble = revenue | [`Retail/Store Quadrant`](Store%20Quadrant) |
| **ABC/XYZ Matrix** | Revenue contribution × demand variability 3×3 matrix with stock policy hints | [`Retail/ABC-XYZ Matrix`](ABC-XYZ%20Matrix) |
| **Weeks of Cover** | Weeks of cover vs target band, with stock value, OOS % and aged stock % | [`Retail/Weeks of Cover`](Weeks%20of%20Cover) |
| **Sell-through Curve** | Cumulative sell-through % by week since launch vs plan and target | [`Retail/Sell-through Curve`](Sell-through%20Curve) |

Each folder has its own README with the data model, properties and deployment steps.
