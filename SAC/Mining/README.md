# Mining — SAC custom widgets

> Proprietary — © 2026 The Data Co (Pty) Ltd. All rights reserved. See [LICENSE](../../LICENSE).

Mining operations: material flow, resources, plant performance, reconciliation, equipment, cost position and safety. Units default to copper (t, % Cu, US$/lb) and are configurable.

| Widget | What it shows | Folder |
|---|---|---|
| **Mine-to-Mill Sankey** | Tonnes from pits through stockpiles, crusher and mill to concentrate, with grade | [`Mining/Mine-to-Mill Sankey`](Mine-to-Mill%20Sankey) |
| **Grade-Tonnage Curve** | Tonnes and average grade above cut-off, with a cut-off read-out | [`Mining/Grade-Tonnage Curve`](Grade-Tonnage%20Curve) |
| **Recovery vs Head Grade** | Plant recovery vs feed grade with fitted curve and target band | [`Mining/Recovery vs Head Grade`](Recovery%20vs%20Head%20Grade) |
| **Metal Balance & Reconciliation** | Stage metal balance with F1/F2/F3 reconciliation factors | [`Mining/Metal Balance`](Metal%20Balance) |
| **OEE Time-Usage Waterfall** | Calendar → direct operating hours waterfall with A/U/E/OEE | [`Mining/OEE Time Usage`](OEE%20Time%20Usage) |
| **Fleet Status Timeline** | Equipment status lanes across the shift with % operating | [`Mining/Fleet Status Timeline`](Fleet%20Status%20Timeline) |
| **Cost Curve** | Industry cost curve with own assets, quartiles and price line | [`Mining/Cost Curve`](Cost%20Curve) |
| **Safety Pyramid** | Incidents by severity with LTIFR / TRIFR | [`Mining/Safety Pyramid`](Safety%20Pyramid) |

Each folder has its own README with the data model, properties and deployment steps.
