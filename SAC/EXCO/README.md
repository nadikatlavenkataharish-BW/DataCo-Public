# EXCO — SAC custom widgets

> Proprietary — © 2026 The Data Co (Pty) Ltd. All rights reserved. See [LICENSE](../../LICENSE).

Executive dashboards: headline KPIs, attainment, variance hot-spots and value-driver trees for board and EXCO packs.

| Widget | What it shows | Folder |
|---|---|---|
| **Variance KPI Tile** | Headline Actual with ▲/▼ variance vs Plan and Prior Year, plus a sparkline | [`EXCO/Variance KPI Tile`](Variance%20KPI%20Tile) |
| **Bullet Chart** | Actual vs Target with % of target bands and a Forecast marker | [`EXCO/Bullet Chart`](Bullet%20Chart) |
| **Variance Heatmap** | Row × column variance % with RAG or diverging colour and totals | [`EXCO/Variance Heatmap`](Variance%20Heatmap) |
| **Driver Tree** | Value driver tree (e.g. ROCE → margin × turnover) with actual, plan and RAG per node | [`EXCO/Driver Tree`](Driver%20Tree) |

Each folder has its own README with the data model, properties and deployment steps.
