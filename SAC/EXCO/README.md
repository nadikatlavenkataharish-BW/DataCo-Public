# EXCO — SAC custom widgets

> Proprietary — © 2026 The Data Co (Pty) Ltd. All rights reserved. See [LICENSE](../../LICENSE).

Executive dashboards: headline KPIs, attainment, variance hot-spots and value-driver trees for board and EXCO packs.

| <a href="Bullet%20Chart"><img src="Bullet%20Chart/Example.png" width="260" alt="Bullet Chart"/></a> | **[Bullet Chart](Bullet%20Chart)** | Actual vs Target with % of target bands and a Forecast marker |
| <a href="Variance%20Heatmap"><img src="Variance%20Heatmap/Example.png" width="260" alt="Variance Heatmap"/></a> | **[Variance Heatmap](Variance%20Heatmap)** | Row × column variance % with RAG or diverging colour and totals |
| <a href="Driver%20Tree"><img src="Driver%20Tree/Example.png" width="260" alt="Driver Tree"/></a> | **[Driver Tree](Driver%20Tree)** | Value driver tree (e.g. ROCE → margin × turnover) with actual, plan and RAG per node |
